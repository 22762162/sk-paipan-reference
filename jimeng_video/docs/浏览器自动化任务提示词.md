# 用 Claude in Chrome 在即梦网页版自动生成（配套提示词）

前置：Mac 上装好 [Claude in Chrome 扩展](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn)（需 Pro/Max/Team/Enterprise 订阅），
本地装好 Claude Code，在**生成包目录**里启动：

```bash
cd "~/Library/Mobile Documents/com~apple~CloudDocs/4k高清/卡卡学姐的第一课_手机Seedance2生成包"
claude --chrome
```

然后把下面整段提示词粘贴给它（首次浏览器操作会弹权限确认，点允许）。

---

请帮我在已登录的即梦网页版（jimeng.jianying.com）逐段生成《卡卡学姐的第一课》的 7 段视频。
当前目录就是生成包：参考帧在 `00_参考帧/`，逐段提示词在 `01_逐段提示词/`（U01.txt…U07.txt）。

每一段的设置完全相同：
- 模型：Seedance 2.0；模式：首尾帧生成（首帧+尾帧）；清晰度：720p；时长：15秒；生成数量：1条
- 画幅 9:16 竖屏由参考图自动识别，不要手动改
- 声音：使用 Seedance 2 自带的配音/音频（保持开启）
- 不要字幕、贴纸、片头文字、水印

严格按 U01→U07 顺序，每段：
1. 上传首帧和尾帧（从 `00_参考帧/` 选对应文件，见下表，不能换图/裁图/加滤镜）；
2. 打开 `01_逐段提示词/U0X.txt`，把全文原样粘贴进提示词框（不增删）；
3. 核对上面的设置后点生成，等待完成（可能要几分钟，耐心轮询）；
4. 下载原始 720p 视频（不要二次压缩），保存为 `05_生成视频放这里/U0X.mp4`；
5. 下载完成后再开始下一段。

全部 7 段下载完成后，在本目录运行：
1. `python3 -m jimeng_video check .` —— 如有 FAIL，告诉我是哪段哪项，先别拼接；
2. 校验通过后 `python3 -m jimeng_video assemble .` —— 输出 102 秒成片到 `06_成片/`。

（jimeng_video 工具来自仓库 22762162/sk-paipan-reference 的 `claude/jimeng-video-cli-7azy0f` 分支；
若本机没有，先 `git clone` 该仓库并把仓库根目录加进 `PYTHONPATH`，或在仓库根目录里以
`python3 -m jimeng_video check "<生成包目录>"` 方式运行。assemble 需要 `brew install ffmpeg`。）

生成过程中若遇到登录页、人机验证或余额/权益弹窗，停下来叫我处理。
每段生成完先按包里 README 的 6 项人工目检口径粗看一眼画面（人物只有卡卡和小豆、发色制服稳定、
道具不畸形、无可读文字水印、结尾自然到达尾帧姿势），可疑就截图问我要不要重做，不要自作主张重生成扣次数。
