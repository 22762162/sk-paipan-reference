# AIFOS 出图与视频失败经验基线

更新时间：2026-08-01。适用于所有 AIFOS 漫剧项目。

## 真实失败底稿

- 82 次图片 QC 中，50 次存在可见画面问题，65 次存在输入合同问题。
- 67 条失败任务中，32 条属于提示词/事实合同冲突，14 条属于 Provider 不可用。
- 高频可见问题依次集中在镜头语言、服装与道具、构图、空间物理和人物身份。
- 上述数据是观察性结论，不单独证明因果；但参考职责唯一化、镜头合同唯一化和提交前额度检查属于可确定的低成本改进。

## 四层处理边界

1. 生成前硬检查只处理确定性矛盾，并且只隔离当前镜头：互斥镜头语言、人数不一致、时代禁物、参考职责冲突、参考额度超限、单动作包含多阶段、复杂动作缺少三态。
2. 生成后内容问题在创作选片模式下只做标注与选片建议，不阻断、不自动返工、不伪造 QC 通过。
3. 视频用起始、过渡、结束状态链检查人物、道具、相机和空间连续性；每段只允许一个主动作和一个运镜。
4. Provider、文件落盘、编码、解码、分辨率、时长和音轨完整性属于技术检查，始终保留；技术错误最多按策略重试，且必须消费上一轮诊断。

## 高频失败到前置解法

| 过去的失败 | 主要成因 | 现在必须前置解决 |
|---|---|---|
| 人脸、发型、妆造不像参考图 | 身份参考与服装/场景参考职责混杂 | 身份锚独占脸、发型、妆造；服装只管衣着；四张候选共用同一绑定表 |
| 都市模板衣服套到古装、职业或特殊身份 | 提示词从通用画风倒推人物，没有先读剧情事实 | 先提取年代、职业、阶层、处境和当前服装状态，再写当镜可见造型 |
| 场景串时代、家具和道具乱位 | 剧本文字、空间图和镜头合同互相冲突 | 镜头提交前核对时代、空间坐标、人物站位、相机方向和道具唯一位置 |
| 马车没马、屏幕方向反了、人物穿模或悬浮 | 只检查“画了什么”，没有检查支撑、连接和因果 | 生成前列出必须出现的功能对象；生成后检查支撑、接触、朝向、遮挡和动作因果 |
| 屏幕文字乱码、合同提示词被画到屏幕上 | 没有区分可见文字白名单和内部控制字段 | 只允许逐字给出的屏幕文字进入画面；内部提示、镜头合同、Logo和水印全部禁止可见 |
| 镜头提示词很长仍不准确 | 把整份人物史、旧失败和无关规则一起塞入 | 每镜只保留当前可见事实、一个主动作、一个运镜和最多5条相关防错规则 |
| 失败图反复原样重画 | 上轮诊断没有真正改变下一轮输入 | 只有形成明确修订片段或修正参考绑定才允许返工；无有效修改则停止盲抽 |
| 内容小瑕疵拖死整集 | 内容质检和生产线程内联，失败即阶段失败 | 内容质检异步标注；其他镜头继续；人工从四张中选最优或整组改词重抽 |
| 视频跑脸、道具瞬移、动作倒放 | 只检查文件存在或单帧，没有跨时间状态链 | 联合审查0/25/50/75/100%五帧，比较人物、服装、空间、道具和动作起承转合 |
| 网络、Provider或重启导致假失败 | 技术异常和创作质量混为一类 | 技术失败单独恢复同任务或断点；不得把服务中断记成人物/画风教训 |

## 十条可执行短规则

1. 一镜只准一组画幅、景别、角度、焦段、视角和运镜；互斥即隔离本镜。
2. 每张参考图只担一项主职责；超运行时上限先精简或拆镜，禁止静默丢图。
3. 身份锚只锁脸、年龄、性别、发型和妆造，不得被服装模特或他人参考覆盖。
4. 逐镜写明到场名单与整数人数，禁止模糊人数、复制、漏人或多余人物。
5. 服装和头饰独立锁定形制与状态；时代禁物命中时先修合同再生成。
6. 可读文字先建白名单并在静态关键帧锁定，视频不得自行生成或改写文字。
7. 人物、相机、家具和道具先核对碰撞、支撑、朝向、持有与唯一位置。
8. 复杂动作至少锁起点、过渡、终点三态；每段只执行一个主动作和一个运镜。
9. 同集统一使用即梦内置配音与口型同步；有音轨不等于口型已验证。
10. 提交前检查 Provider、参考上限和编码；重试必须按上轮诊断修改输入或恢复技术链路。

## 提示词注入原则

- 每个镜头只选择与当前上下文相关的最多 5 条规则。
- 不把全部历史失败、其他场景、其他角色或其他生成环节塞进当前提示词。
- 规则短、明确、可执行；事实来自剧本、锁定资产、空间图和镜头合同，经验只负责防止重犯，不新增剧情事实。

## 已固化到产线的纠错机制

- 每镜固定生成 4 张独立候选；四张共用同一份已审核提示词、参考图清单和风格合同，只利用 Provider 的受控随机差异，不用“不同风格”制造假多样性。Provider 明确支持 seed 时才传真实 seed 并记录；不支持时只记录候选 variation id，不宣称可复现。
- 候选图不会自动晋升正式资产；只能由人工明确选择，或由用户主动触发的 AI 选优确认。整组重抽会保留历史版本，旧结果不得覆盖新版本。
- 创作选片模式默认开启：图片/视频内容质检只作建议，不阻断其他镜头、不自动返工；生成前合同检查和媒体技术检查始终开启。
- 视频内容质检开启时，对真实成片按 0/25/50/75/100% 抽取 5 帧并联合检查跑脸、服装/场景漂移、道具瞬移、穿模悬浮、支撑断裂、设备反向和动作阶段倒置；证据帧永不登记资产、永不进入参考链。
- 视频内容失败只允许携带明确原因和定向提示词修订自动返工 1 次；第二次仍失败转人工。关闭内容质检时完全不抽帧、不调用 AI。
- 视频无论是否关闭内容质检，都必须实测视频流、720×1280、帧率、时长和即梦内置音轨；ffprobe 不可用时使用 ffmpeg 只读回退，二者都不可用则技术不放行。
- 编剧只接收紧邻前集的出口状态、未决钩子和仍有效事实，不接收前集全文；九宫格只作人工审片浏览，一格一镜，不生成拼贴参考资产。
