# AIFOS 规则治理与生产流程

## 目标

规则只在自己的范围内生效。一次质检失败不得自动变成跨项目、跨剧集或
跨镜头的永久提示词。遇到冲突时，系统按唯一优先级裁决，而不是把两条
互斥指令一起发送给模型。

## 唯一优先级

1. 用户已经锁定的事实或逐项人工修订(含人工改选的图片资产定版)
2. 本集正式剧本、制作圣经与图片资产定版(CODEX 评选自动确认或人工确认)
3. 当前镜头合同
4. 本集制作标准快照、质量策略与人物资产策略
5. Provider 能力边界
6. 系统默认和旧数据兼容回退

低优先级只能补缺，不能覆盖高优先级事实。Provider 只能验证、执行或
阻断，不能静默改人物、参考图、质量或生产规格。

## 四类规则

| 范围 | 可以包含 | 生命周期 | 是否进入其他镜头 |
|---|---|---|---|
| 系统永久规则 | 身份、性别、人数、物理、文字白名单、参考图绑定、文件完整性 | 永久 | 是 |
| 项目/本集事实 | 时代、画风、服装、道具、允许的跨时代物件 | 项目或本集结束 | 仅同项目/本集 |
| 当前镜头合同 | 机位、构图、动作、站位、起止状态 | 镜头版本变化即失效 | 否 |
| 一次性修复规则 | 本次提示词补丁、参考图调整 | 通过或自动修复一次即失效 | 否 |

质检发现的问题先进入“待审核观察库”，不自动写入永久规则。确实需要
跨镜头复用时，必须由人工明确批准适用范围并形成新版本。

## 强制门禁与导演建议

身份、性别、人数、连续性、物理空间、文字、参考图输入合同、首尾帧、
声音和实际生产规格是系统永久硬门，不能关闭或降成警告。

反应镜数量、景别跳级、机位变化等创作启发属于导演建议。建议会出现在
报告中，但不扣质检通过分，也不阻断一条有明确导演意图的镜头。

## 一次综合质检

每张图片只做一次综合质检，同时收集：

- 角色身份、性别和人数
- 可见角度对应的身份依据
- 物理与空间关系
- 可读文字和时代事实
- 当前镜头提示词是否准确、简洁、无冲突
- 本次实际上传的参考图是否正确、完整、用途绑定一致

第一次失败后，只允许依据诊断修改当前镜头的提示词或参考图并自动重做
一次。第二次仍失败时，该项进入“等待人工”，系统继续生产不依赖它的
其他镜头；禁止原样重复调用和把失败补丁追加到其他镜头。

人工可以放行轻微表情或审美偏差，但不能强行放行身份、性别、人数、
物理空间或提示词/参考图输入合同错误。

## 候选评选与自动确认

一组画面固定生成 4 张候选，由 CODEX 主导的视觉评选按本剧本要求打分，
自动确认其中一张为该组定版母资产。评选属于"选择"，不是"放行"：

- 评选只在同组四张之间横向比较，剧本没写的细节不是扣分项；
- 评选产线不可用、应答结构非法、判定四张都有硬伤或把握不足时，
  一律不锁定，整组退回人工四选一，绝不猜测定版；
- 自动确认不替代任何硬门。定版母资产之后仍要经过一次综合质检、
  参考图输入合同和开拍门禁；
- 人工改选优先级最高：改掉已确认的母资产会作废由它派生的下游图，
  并退回定版检查点重新确认。

## 推荐生产顺序

```text
导入小说/剧本源文档
  → 编剧影视化改编 + 一次综合逻辑审查
  → 人工锁定正式剧本
  → 每组画面 4 张候选(人物/核心道具/场景同批并行)
  → CODEX 评选自动确认 1 张(评选不下判断时退回人工四选一)
  → 简化/完整人物资产策略
  → 五维分镜 + 火柴人空间调度
  → 代表性 15 秒小样计划
  → 关键帧
  → 首尾帧视觉质检
  → 一次付费生产确认
  → Seedance 默认 4 路并行
  → 视频与交付质检
```

批量导入的解析稿只是源素材，必须经过编剧总闸门，不能直接成为正式
剧本。正式图片调用付费 API 时必须携带真实参考图；初次人物探索没有
身份参考时，只允许走 Codex 订阅通道，不允许 Seedream 或 OpenAI 图片
API 退化成纯文字生图。

## 《大明》重制原则

旧《大明》项目作为历史证据保留，不再在原项目上叠加修复规则。重制时
新建独立项目/版本，重新导入源文档，并按上述流程从编剧总闸门开始。
不得复制旧项目的待审核质检观察、一次性修复补丁、失败图片或旧标准
快照；只迁移用户明确锁定并再次确认的人物/世界事实。
